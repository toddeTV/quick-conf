# Ticket Sales & Payments

This template front-end can link to any ticket provider.

## Integration

1. Edit `content/tickets/*.yml`.
2. Set the `button.to` field to your external ticket provider URL (e.g., Stripe Payment Link, Eventbrite, Tito).

## Free Events

If your event is free, point the link to a registration form.
